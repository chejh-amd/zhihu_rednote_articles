## 标题

没AMD GPU怎么用大模型？3步上手

## 正文

本来只想调个大模型，教程却让我先准备显卡、装驱动、配环境。模型还没回我一句话，电脑先给我上了一课。

如果只是想试模型或验证想法，可以先走云端。Token Factory有点像“大模型自助区”：网页里挑模型、创建API Key，再接进代码。显卡可以慢慢选，想法先跑起来。

🏭 它是做什么的

Token Factory部署在Radeon Cloud上，把模型目录和API入口放到了一起。你可以查看模型ID、上下文长度、服务状态和参考价格，再决定用哪个。

不过现在还是Beta版，用来熟悉功能、试接口、做Demo更合适。真要接进业务，超时、重试和备用模型还得提前安排好，别让Demo跑得欢，上线就抓瞎。

🍽️ 三类服务怎么选

1️⃣ 想先试试看：用共享模型。

2️⃣ 想要独享资源：使用 Radeon Cloud Credits 部署 Dedicated Model。

3️⃣ 想体验合作伙伴模型：按对应平台的规则申请和使用。

🔑 三步创建API Key

1️⃣ 登录 AMD 开发者会员
2️⃣ 进入 AMD 开发者云
3️⃣ 打开 Token Factory，选模型、创建并复制 API Key

还没注册过的话，可以翻翻主页之前那篇，注册流程已经整理过了。

共享模型目前支持 OpenAI-compatible API。手里有调用 OpenAI SDK 的代码，换掉模型 ID 和接口配置，就能直接拿来试。

🧮 1 积分能用多久？

每个账号每天有 1 积分通用 API 额度，北京时间刷新，当天没用完也不会攒到明天。

调用模型会扣多少，要看输入、输出和缓存价格。同样是 1 积分，选的模型不同、对话长短不同，能用的 Token 数也不一样。所以开聊前先瞄一眼模型卡，免得聊到兴头上突然余额不足。

⏰ 用之前留意这几点

模型和价格会不定期调整，打开页面看当时的状态就好。碰上大家都在用的时候，回复可能慢一点，不一定是代码写错了，过会儿再试试。
